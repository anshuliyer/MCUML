# MixedSignalIDE Installation

This folder contains the installation helper for MixedSignalIDE.

Files:
- `requirements.txt` - Python dependencies for the project.
- `install.sh` - Creates a virtual environment and installs dependencies with an animated installation banner.
- `manage.sh` - Interactive SDK manager for installing and entering the venv.
- `venv/` - The local virtual environment created by the installer.

Usage:

1. Run the installer:
   - `bash install.sh`
2. Start the SDK manager:
   - `bash manage.sh`
3. In the SDK manager, choose option 2 to enter the venv.
